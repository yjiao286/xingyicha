# 文本查重模板过滤优化设计

2026-06-17

## 背景

当前系统的文本查重（`text_similarity_analysis`）有三层模板过滤：
1. **参照文件匹配**（`_is_in_reference`）：用户上传的招标文件作为参照，出现的段落标记为模板
2. **`is_template_content()`**：硬编码约 10 个模板标记词，仅对 `< 30` 字符的段落生效
3. **`classify_abnormal_reason()`**：对被标记为异常的段落给出原因分类

存在问题：
- `is_template_content()` 仅覆盖短段落，且标记词太少
- 没有自动发现"跨多文件共现 = 模板"的机制
- 长段落模板套话（法律声明、标准条款等）可能被误判为异常一致
- 异常一致的判定是二元的（异常/非异常），缺少中间态

## 优先级

A（全量共现型）> C（长段落模板型）> B（短格式标记型）

## 设计

### 1. 全局共现索引（Type A）

**位置**：`text_similarity_analysis()` 函数开头，在配对比较之前。

**算法**：
```
1. 将所有标书文本按滑动窗口切成段落（窗口 100 字，步长 50 字）
2. 对每个段落做轻量级归一化（去除多余空白、统一全角/半角标点）
3. 建哈希索引：{hash(归一化段落): [出现该段落的文件名列表]}
4. 标记规则：
   - 段落在 ≥ max(3, ceil(N × 50%)) 个文件中出现 → "全局模板段落"
   - N=2 时阈值=2（两两重复仍保留比对），N≥3 时按比例
5. 在后续配对遍历中，命中的段落如已在全局模板集合中 → 标记为 template
```

**关键参数**：
- 窗口大小：100 字符（足够覆盖一个有意义的句子）
- 步长：50 字符（保证覆盖不同切分）
- 最小文件数阈值：`max(3, ceil(N × 50%))`

**新增数据结构**：
```python
'global_template_count': 0,    # 全局共现过滤的段落数
```

### 2. 扩展模板规则库（Type B + C）

**改动 `is_template_content()`**：去掉 `len(text) < 30` 限制，全长度覆盖。

**规则分类**：

| 类别 | 检测方式 | 示例 |
|------|---------|------|
| 签字/盖章/日期 | 关键词匹配 | "法定代表人或其委托代理人"、"授权代表签字"、"（签字）"、"（盖章）"、"供应商全称" |
| 招标公告固定措辞 | 短句匹配 | "投标人须知"、"招标文件的获取"、"投标文件递交"、"发布公告的媒介" |
| 法律/标准条款 | 关键词 + 段落特征 | "根据《中华人民共和国招标投标法》"、"符合《政府采购法》"、"信用中国"、"失信被执行人" |
| 格式套话/声明 | 关键词 | "我公司郑重承诺"、"具有独立承担民事责任的能力"、"近三年内在经营活动中没有重大违法记录"、"具有良好的商业信誉和健全的财务会计制度" |
| 通用编号/项目信息 | 正则 | "项目编号："、"采购编号："、"招标编号："、"包号"、"标段" |
| 目录/分隔/页码 | 正则 | "目 录"、纯页码行、章节编号格式 |

### 3. 实质性评分（`_score_substantiality()`）

对未被全局索引和规则库过滤的段落，计算实质性分数（0–1）。

| 维度 | 权重 | 计算方法 |
|------|:---:|---------|
| 段落长度 | 30% | min(1, len(text)/200) |
| 技术/业务术语密度 | 30% | 技术名词（型号、参数、专用术语）占字符比例 × 系数 |
| 数值/编号特异性 | 25% | 含具体金额、百分比、日期、版本号、人员姓名等 |
| 句式模板化程度（反向） | 15% | 检测"应当/必须/不得/承诺/保证"密度，无具体信息则扣分 |

**评分阈值**：

| 分数 | 标签 | 参与结论 |
|:---:|------|:---:|
| ≥ 0.6 | 实质性异常（substantial_abnormal） | 是 |
| 0.3–0.6 | 疑似模板（suspicious_template） | 否 |
| < 0.3 | 确认为模板（template） | 否 |

### 4. 前端展示

三级标记显示：
- 🔴 **实质性异常**：红色高亮，参与结论判定
- 🟡 **疑似模板**：黄色/橙色，展示但不参与结论，已降级
- ⚪ **已过滤模板**：灰色，默认折叠

每个文件对的匹配列表按三级分组展示。

### 5. 结论判定调整

第（四）项-a "投标文件异常一致" 改为只看实质性异常：

```python
'satisfied': len(similarity.get('substantial_abnormal', [])) > 0
```

evidence_level：
- 有实质性异常 → `'强'`
- 有疑似但无实质性 → `'中'`
- 全部为模板 → `'无'`

### 6. 数据流

```
标书文本 → find_common_segments() 发现共享段落
    → 全局共现索引过滤 (Type A: 跨文件共现 = 模板)
    → 规则库过滤 (Type B+C: 模板标记词、格式套话)
    → 实质性评分 (_score_substantiality)
        → ≥ 0.6: substantial_abnormal (参与结论)
        → 0.3–0.6: suspicious_template (展示但降级)
        → < 0.3: template (已过滤)
    → 结论判定仅使用 substantial_abnormal
```
