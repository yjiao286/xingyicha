# 银河麒麟操作系统（Kylin OS）部署指南（星易查）

适用于银河麒麟桌面操作系统 V10（含 SP1/SP2/SP3）及银河麒麟高级服务器版 V10。
功能与 Windows / macOS / 主流 Linux 桌面版完全一致。

## 一、第一步：确认 CPU 架构

银河麒麟随 CPU 架构发布不同版本，**请先在终端执行 `uname -m` 确认架构**，再
按对应方式部署：

| `uname -m` 输出 | 典型 CPU | 部署方式 |
|-----------------|----------|----------|
| `x86_64` | Intel / AMD / 海光 / 兆芯 | 优先用 Release 预编译包（第二节，注意 glibc 兼容性），或源码部署 |
| `aarch64` | 飞腾 FT/D 系列 / 鲲鹏 920 / 麒麟 990 | 暂无预编译产物，走源码部署（第六节） |
| `loongarch64` / `mips64` | 龙芯 3A5000/3C5000 等 | 源码部署，OCR 依赖需自行解决（见常见问题） |

## 二、x86_64 麒麟：安装桌面版（推荐 tar.gz 便携版）

1. 从 GitHub Release 页面下载（与 Windows/macOS 版同源同版本）：
   **`XingYiCha-linux-x86_64.tar.gz`**（推荐，无 FUSE 依赖，离线可用）
2. 安装运行依赖（联网机器）：

   ```bash
   sudo apt install libgl1 libegl1 libglib2.0-0
   ```

3. 解压运行：

   ```bash
   tar xzf XingYiCha-linux-x86_64.tar.gz
   ./XingYiCha/XingYiCha
   ```

启动后自动打开浏览器访问 `http://127.0.0.1:5001`，关闭终端窗口即停止服务。
数据目录：`~/.local/share/星易查/`（history 与 uploads）。

**AppImage 备选**（`XingYiCha-x86_64.AppImage`）：需先安装 FUSE：

```bash
sudo apt install libfuse2
chmod +x XingYiCha-x86_64.AppImage
./XingYiCha-x86_64.AppImage
```

在 UKUI 文件管理器中双击运行时，右键文件 → 属性 → 权限，勾选"允许作为程序
执行"；命令行 `./` 运行不受限。

### ⚠️ glibc 兼容性提示（重要）

Release 的 Linux 产物构建于 Ubuntu 22.04（glibc 2.35），而银河麒麟 V10 基于
Ubuntu 20.04（glibc 2.31）。如启动时报如下错误，说明系统 glibc 低于构建环境：

```
/lib/x86_64-linux-gnu/libc.so.6: version `GLIBC_2.34' not found
```

可用 `ldd --version` 查看本机 glibc 版本。**遇到该错误请改用第六节源码部署**
（信创环境下源码部署最稳，一次配好可长期使用）。

## 三、麒麟安全管控放行

银河麒麟默认开启安全增强（KYLSEC）。若双击或命令行启动被拦截、提示"未经
授权的程序"或日志中出现 kysec 拦截记录：

1. 打开「安全中心」→ 应用程序执行控制，将 `XingYiCha`（或解压目录）加入
   可信程序名单；
2. 或临时验证：`sudo setstatus softmode`（切换为软模式仅用于排查，验证后
   建议恢复原状态）。

## 四、.doc 正文提取（可选依赖）

麒麟桌面通常预装 WPS Office，但本软件 .doc 正文转换依赖 **LibreOffice**（WPS
不可替代）：

```bash
sudo apt install libreoffice   # 或在麒麟软件商店搜索安装
```

未安装时 .doc 正文维度自动跳过，元数据比对、其余格式与维度完全不受影响。

## 五、离线（内网）安装

党政内网机器通常不联网，tar.gz 便携版本身免安装、免联网，只需三个系统库。
在一台**同架构、同版本**的联网麒麟机上下载 deb 后拷贝安装：

```bash
# 联网机上执行，生成 deb 包
apt download libgl1 libegl1 libglib2.0-0 libfuse2
# 拷贝到目标机后安装
sudo dpkg -i *.deb
```

deb 包也可从银河麒麟官方 ISO/软件源获取。

## 六、aarch64（飞腾/鲲鹏）与其他架构：源码部署

预编译产物当前仅 x86_64。飞腾/鲲鹏等 ARM 机器按以下步骤部署（麒麟 V10 自带
Python 3.8，满足要求；依赖 PyMuPDF、onnxruntime 等均提供 aarch64 Linux 轮子）：

```bash
# 1. 安装基础工具（未预装时）
sudo apt install python3 python3-venv python3-pip

# 2. 获取源码（git 或直接下载源码包拷贝进内网）
git clone git@github.com:yjiao286/xingyicha.git
cd xingyicha

# 3. 创建虚拟环境并安装依赖
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 4. 启动
python3 app.py 5001
```

启动后浏览器访问 `http://<机器IP>:5001`（局域网使用需放开防火墙对应端口，
或将启动命令改为 `HOST=0.0.0.0 python3 app.py 5001`）。

**常驻运行**（服务器/多人共用场景）：

```bash
nohup ./venv/bin/python3 app.py 5001 >/var/log/xingyicha.log 2>&1 &
```

或编写 systemd 服务单元开机自启；生产模式也可使用仓库根目录 `Dockerfile` +
`docker-compose.yml`（麒麟服务器版支持 Docker）。

## 七、常见问题

- **报 `GLIBC_2.xx not found`**：系统 glibc 低于构建环境（见第二节提示），
  改用源码部署。
- **报 `libGL.so.1: cannot open shared object file`**：`sudo apt install
  libgl1`（离线机用第五节 dpkg 方式）。
- **AppImage 双击无反应**：未装 libfuse2 或未勾选"允许作为程序执行"；命令
  行 `./` 运行验证，或直接用 tar.gz 便携版。
- **程序被安全管控拦截**：见第三节。
- **龙芯（loongarch64）机器**：onnxruntime 无官方 LoongArch 轮子，RapidOCR
  装不上时属预期——OCR 为可选依赖，缺失时扫描件 PDF 自动跳过，其余功能完整；
  如需 OCR 可从麒麟软件源寻找 onnxruntime loongarch 移植包。
- **端口占用**：自动改用 5002-5010，以终端打印的实际地址为准。
- **上传文件 / 历史记录在哪**：`~/.local/share/星易查/uploads` 与
  `~/.local/share/星易查/history`。
